# AI Building Intensive — student pack

Course materials for **Part 1: Rapid prototyping with AI**.

## Get the files (no git required)

1. Click the green **Code** button on GitHub.
2. Choose **Download ZIP**.
3. Unzip the folder.

Then open `student/design-preview/index.html` in Chrome to pick a look. Your instructor will send the pre-work checklist separately.

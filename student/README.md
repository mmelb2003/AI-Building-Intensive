# After the first screen

Bootstrap is the root `README.md`. Do not copy this folder into the app.

Once something is on screen, copy from **your Downloads pack** (not from the app):

1. `student/specs/_template.md` and `student/specs/README-seed.md` → your app as `specs/_template.md` and `specs/README.md`
2. `student/handoff/HANDOFF-Template.md` → your app as `HANDOFF.md`

Then tell Cursor:

> Write spec 001 for the slice that is already on screen. Follow the spec-writing skill. Use `specs/_template.md`.

End of a session:

> Wrap up this session. Update `HANDOFF.md` so the next agent can pick up cleanly.

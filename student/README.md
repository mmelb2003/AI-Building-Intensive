# Student pack

Everything you need before and during Day 1.

| File | What it is |
|------|------------|
| `gallery/index.html` | Same workshop homepage in five looks — pick one |
| `design-systems/` | The five `DESIGN.md` options (Harbor, Studio, Console, Garden, Signal) |
| `cursor-pack/` | One workshop rule — copy it so the agent stays on the rails |
| `prd/` | The PRD template + a worked example ("Loop") — copy one into your app as `PRD.md` |

## Pick a look (2 minutes)

1. Open `gallery/index.html` in Chrome.
2. Click the tabs until you like one.
3. Copy that file from `design-systems/` into **your app project** and rename it `DESIGN.md`.
4. Copy `cursor-pack/rules/workshop.mdc` into **your app project** as `.cursor/rules/workshop.mdc` (see `cursor-pack/README.md`).
5. Copy `prd/PRD-Template.md` into **your app project** as `PRD.md` and fill in sections 1–4 (see `prd/README.md`). No idea yet? Use `prd/PRD-Example-Loop.md` instead.
6. Tell Cursor: *Read `PRD.md` and `DESIGN.md`. Follow the workshop rule.*

If you cannot decide, use **Harbor** (`design-systems/01-harbor.md`).

What you will be able to do

The goal is not to become an engineer in a week. It is to become someone who can steer a coding agent and ship a real prototype.

Prototype to learn

Use a build to test value, usability, requirements, and feasibility — then change the product from evidence.

Work with a coding agent

Give Cursor a PRD, review the diff, and iterate. You direct. The agent builds fast and literally.

Ship real software

Get off your laptop: GitHub, a live Vercel URL, an API, a database, and a simple AI feature.

The three days

Twelve short chunks. One project, carried all the way through.

Day 1Think & prototype

Why the build loop got short. Design thinking. First one-shot in Cursor. Then a PRD — and a much better second build.

Day 2Build & ship

Test with a real person. Deploy a URL. Add an API and a database. Keep secrets out of your code.

Day 3Polish & extend

Lightweight tests. Add a chatbot. Level up how you brief the agent. Demo and pack the portfolio.

Bring a problem you actually care about.

Lock one idea on Day 1. Leave on Day 3 with a live prototype you can show at work on Monday.
